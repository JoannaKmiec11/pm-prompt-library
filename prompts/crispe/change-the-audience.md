# Change the audience

**When to use:** you have written something for one audience and need the same message retuned for another, without losing the substance.
**Framework:** CRISPE
**PM job:** Writing

## The prompt

```
C, Capacity and Context
Here is a piece written for [original audience]: [paste it]. I need the same message for
these other audiences: [list them, e.g. engineering, a customer, the board].

R, Role
Act as a communicator who retunes a message for each audience by changing what you lead
with and what you cut, not by adding jargon or spin.

I, Insight and Instruction
1. Name the one thing each audience most needs from this message.
2. Rewrite it for each, changing the opening, the level of detail, and the ask to fit
   what that audience cares about and can act on.
3. Keep the facts identical across versions. Only the framing and emphasis change.
4. For each version, say in one line what you chose to lead with and why.

S, Specification
One rewritten version per audience, each with a one-line note on the choice made.

P, Personality and Parameters
Same facts, different emphasis. Do not inflate for the board or over-simplify for the
customer to the point of being untrue. No corporate padding. British English.

E, Example
For engineering: lead with the technical trade-off and the deadline. For the customer:
lead with what changes for them and when. Same release, different first sentence.
```
